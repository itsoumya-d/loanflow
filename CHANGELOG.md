# Changelog

All notable changes to this project are documented here.

## [1.0.0] - 2026-11-04

### Added

- Laravel 13 / PHP 8.x lending application API with a validated state machine.
- OAuth 2.0 authorization server via Laravel Passport, including client credentials.
- Keap CRM contact upsert, token refresh, retries and signed webhook ingestion.
- BigQuery streaming export with service-account JWT authentication.
- GTM dataLayer contract, custom template and signed server-side event forwarding.
- WordPress intake plugin with shortcode, REST proxy, OAuth token caching, honeypot, rate limiting and accessible form markup.
- Idempotent submissions, hash-chained domain events and audit logs.
- Health, metrics and timeline endpoints.
- GitHub Actions CI across PHP 8.3–8.5, MySQL 8, Node 20–24, plus plugin lint.
- Dockerfile, Compose stack and production PHP/nginx configuration.
- Threat model, architecture notes, ADRs, evidence matrix and clean-room research notes.
